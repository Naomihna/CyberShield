Aturan Firewall

Aturan menentukan apakah sebuah paket diizinkan atau diblokir. Aturan yang sudah ditambahkan langsung dipakai oleh simulasi.

Urutan Keputusan Firewall

Setiap paket diperiksa dengan urutan berikut, dan keputusan pertama yang cocok langsung dipakai.

  1. Cek blacklist. IP sumber ada di daftar blacklist → paket diblokir.
  2. Cek aturan BLOCK yang aktif. IP dan port cocok dengan aturan blokir → paket diblokir.
  3. Cek aturan ALLOW yang aktif. IP dan port cocok dengan aturan izinkan → paket diizinkan.
  4. Tidak ada aturan yang cocok → paket diizinkan (aturan default ALLOW).
